# Табель — учёт рабочего времени и выплат

Программа для Windows (**.exe**) и приложение для Android (**.apk**) в едином
оформлении: светло-серый фон с оттенком голубого неба, акцент — небесно-голубой `#5B9BD5`.

Заменяет бумажную «Карточку учёта рабочего времени и выплат»: день недели и дата
подставляются автоматически, время считается само, деньги — тоже.

---

## Что умеет

**Рабочий день**
- День недели и дата — автоматически, листаются кнопками ◀ ▶ (или PageUp/PageDown).
- Поля «Начало работы» / «Конец работы». Время можно писать как угодно:
  `8`, `8:00`, `8.00`, `0800`, `17.15`, `17:15` — всё распознаётся.
- Галочка **«Был обед»** → раскрывается поле «Обед, минут» с быстрыми кнопками 30/45/60.
  Обед вычитается из рабочего времени.
- Поле «Объём и качество произведённых работ» — что делал за день.
- Галочка **«Дополнительные работы»** → раскрывается блок: начало, конец,
  **своя ставка ₽/час** (у каждого сотрудника может быть своя), либо переключатель
  «оплата фиксированной суммой», плюс описание. Доп. время идёт **отдельным столбцом**.
- Поле **«Премия»** — разовая сумма, вносится вручную.
- Всё считается **на лету**, пока печатаешь: часы, «Оплата за день»,
  «Доп. работы», «Премия», «ИТОГО ЗА ДЕНЬ».

**Неделя** (понедельник — воскресенье)
- Таблица Пн…Вс со столбцами как в бумажной ведомости.
- Итоги: отработано дней, основных часов, доп. часов, премии, **итого к выплате**.
- Двойной клик по строке — открыть этот день на редактирование.

**История**
- Все прошлые недели и месяцы хранятся в базе (SQLite), ничего не теряется.
- Список месяцев, внутри — дни, промежуточные итоги по неделям и итог за месяц.

**Отчёты**
- Excel (.xlsx) — неделя или месяц, готовая таблица с формулами оформления.
- PDF — «Карточка учёта рабочего времени и выплат» в альбомной ориентации,
  один в один по смыслу с бумажной формой. Кириллица корректная (шрифт DejaVu вшит).
- Android: кнопка «Поделиться отчётом» — отправляет текстовую сводку
  в WhatsApp / Telegram / почту.

**Настройки**
- Ставка за час основной работы (по умолчанию 250 ₽) и отдельная ставка доп. работ.
- Значения по умолчанию для нового дня (8:00 — 17:00, обед 60 мин).
- Ф. И. О. работника и организация — попадают в шапку отчётов.
- Резервная копия и восстановление (.json).

## Как считается

| Величина | Формула |
|---|---|
| Рабочее время | `конец − начало − обед` (переход через полночь поддерживается) |
| Оплата за день | `минуты / 60 × ставка` |
| Доп. работы | `минуты доп. / 60 × ставка доп.` **или** фиксированная сумма |
| Итого за день | `оплата за день + доп. работы + премия` |
| Итого за неделю | сумма по дням с понедельника по воскресенье |

Пример из твоей ведомости: `8:00 → 17:20` = 9 ч 20 мин → 9,3333 × 250 = **2333 ₽** ✔

## Структура проекта

```
tabel/
├── core/
│   ├── timecard_core.py    ← ядро: расчёты, модель дня, база SQLite, палитра
│   └── reports.py          ← экспорт Excel / PDF / текст
├── windows/
│   ├── app.py              ← окно программы (Tkinter)
│   ├── ui_kit.py           ← стили и виджеты (карточки, поля, кнопки, плитки)
│   ├── tabel.spec          ← настройки PyInstaller
│   ├── build_exe.bat       ← сборка одним кликом
│   ├── requirements.txt
│   └── assets/             ← иконка + шрифты DejaVu
├── android/
│   ├── main.py             ← приложение (Kivy), то же ядро
│   ├── tabel.kv
│   ├── buildozer.spec      ← настройки сборки apk
│   ├── build_apk.sh        ← сборка одной командой
│   └── assets/             ← иконка, заставка, шрифты
├── .github/workflows/build.yml   ← автосборка .exe и .apk в GitHub Actions
├── test_core.py            ← тесты расчётов на реальных данных
├── test_gui_smoke.py       ← автопроверка окна Windows
└── test_android_smoke.py   ← автопроверка экранов Android
```

Логика расчётов и цветовая палитра лежат в **одном** файле `core/timecard_core.py` —
поэтому Windows и Android считают одинаково и выглядят одинаково.

---

## Сборка Windows (.exe)

Нужен Python 3.10+ с сайта python.org (галочка «Add Python to PATH»).

```
cd windows
build_exe.bat
```

Готовый файл: `windows/dist/Tabel.exe` — один файл, ничего доустанавливать не надо,
можно носить на флешке. Данные пишутся в `%APPDATA%\TabelUcheta\timecard.db`.

Запуск без сборки (для проверки):
```
pip install openpyxl reportlab
python windows/app.py
```

## Сборка Android (.apk)

APK собирается только на Linux (подойдёт Ubuntu в WSL на твоём же Windows).

```
cd android
chmod +x build_apk.sh
./build_apk.sh
```

Готовый файл: `android/bin/tabel-1.0.0-arm64-v8a_armeabi-v7a-debug.apk`.
Скинь его на телефон, разреши «Установка из неизвестных источников» — и всё.

Первая сборка качает Android SDK/NDK, занимает 20–40 минут. Последующие — 2–3 минуты.

## Сборка без своего компьютера (GitHub Actions)

Залей папку в репозиторий GitHub — workflow `.github/workflows/build.yml`
соберёт **и .exe, и .apk** на серверах GitHub. Готовые файлы появятся
во вкладке **Actions → последний запуск → Artifacts**.
